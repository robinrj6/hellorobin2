What I built
Adaptive gate mechanism — per-layer MLP conditioned on diffusion timestep and block depth, learning how much control signal to apply at each UNet layer
Conditioning confidence estimator — lightweight CNN that modulates the gate signal based on estimated control map quality
Trained on 118K COCO images using Canny edge maps as control signal, on FAU's HPC cluster (SLURM)
